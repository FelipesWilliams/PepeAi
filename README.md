# Camera Frame Application

Aplicación de escritorio que crea un marco movible y redimensionable en la pantalla.

## Para desarrolladores

Si quieres modificar el código, sigue estos pasos:

1. Asegúrate de tener Node.js instalado
2. Abre una terminal en este directorio
3. Instala las dependencias:
```bash
npm install
```
4. Para ejecutar en modo desarrollo:
```bash
npm start
```

## Para usuarios

### Instalación

1. Descarga el instalador "Camera Frame Setup.exe" de la carpeta "dist"
2. Ejecuta el instalador
3. La aplicación se instalará automáticamente y creará:
   - Un acceso directo en el escritorio
   - Un acceso directo en el menú inicio

### Uso

1. Haz doble clic en el icono "Camera Frame" del escritorio
2. Un marco rojo aparecerá en la pantalla
3. Puedes:
   - Arrastrar el marco a cualquier parte de la pantalla
   - Redimensionar el marco desde la esquina inferior derecha
   - Minimizar la aplicación (aparecerá en la barra de tareas)
   - Cerrar la aplicación

### Notas
- Al minimizar, la aplicación seguirá funcionando en la barra de tareas
- Haz clic en el icono de la barra de tareas para restaurar la ventana
